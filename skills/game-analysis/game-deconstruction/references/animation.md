# 动画系统拆解维度

## 分析目标

从 Skeleton、Clip/MotionBank、状态机、混合图、事件和重定向资产建立“状态/技能 → 动画选择 → 混合/修正 → 事件输出”的白盒引用模型。

## 动画目录

先记录原始文件名、逻辑路径、类型、骨架引用、源层和哈希，再按功能盘点：

- 待机、移动、转向、起停、跳跃、攀爬、游泳和载具。
- 普攻、技能、受击、格挡、招架、倒地、处决、死亡和复活。
- 上半身叠加、瞄准、持物、表情、对话、交互和过场。
- AI 专属、武器专属、角色变体和环境动画。

记录循环性、Root Motion、骨架、时长、采样率、事件、曲线、同步标记、遮罩、压缩和 LOD 线索。

## 驱动与组织

- 状态机、Blend Tree/Space、蒙太奇/片段、层、Slot、姿态缓存和动画标签。
- 状态条件、优先级、过渡时间、打断、自过渡和回退状态。
- 速度、方向、加速度、转向、姿态、武器、地面状态和技能阶段等参数来源。
- 数据驱动映射、角色覆盖、武器覆盖和共享动画集。

## 运动与匹配

- In-place 与 Root Motion 的职责边界。
- Motion/Pose Search 数据库、schema、轨迹/特征骨骼、Distance Matching 与 Warping 节点及字段。
- 起步、停止、急转、斜坡、台阶和碰撞修正。
- 角色胶囊、导航速度和动画位移不一致时如何校正。

## 叠加与程序化处理

- 骨骼遮罩、Additive、Aim Offset、Look At、手脚 IK、Control Rig 或约束。
- 武器握持、脚底贴合、瞄准、受击和呼吸等层的合成顺序。
- 布料、头发、挂件、Ragdoll 和物理动画如何与基础姿态结合。
- 镜头距离、平台或性能预算是否关闭某些程序化层。

## 事件与同步

- 动画通知/事件、曲线、同步组、命中帧、脚步、VFX/SFX 和镜头触发。
- 连段、技能阶段、碰撞窗口和动画事件之间的权威关系。
- 多角色交互、处决、骑乘或同步动作如何对齐位置与时间。
- 联机动画状态复制、动作预测和校正的配置字段；未解出的运行逻辑标为未知。

## 质量与性能

- 动画 LOD、更新频率、可见性裁剪、骨骼数量和预算分配。
- 压缩误差、关键帧密度、重定向和运行时解压成本。
- 大量 NPC 时是否降低动画精度、关闭 IK 或共享更新。

## 白盒提取与验证

- 追踪 `角色/SkeletalMesh → AnimClass/图 → layer/state/node → Blend/Montage/Clip`。
- 导出骨架 GUID、时长、采样率、循环、Root Motion、Additive、压缩、曲线、Notify、Sync Marker 和 LOD 字段。
- 追踪 `Clip/Montage → skeleton + events/curves → skill/hitbox/VFX/SFX`。
- 追踪 `motion graph → pose-search schema → database → source clips` 及 IK/Retarget/ControlRig 引用。
- 重复解析关键动画资源并用第二预览器核对骨架、时长和事件；实机只验证 Root Motion、过渡与事件时点。

### 动作链闭合的四层门槛

动画“已经找到”必须逐层给出可追溯证据：

1. **状态层**：状态或动作节点使用的选择键、资源引用或运行时标识。
2. **资源层**：选择键怎样映射到实际动画容器。目标格式存在 MotionBank 时，使用完整的 `(BankID, BankType)` 复合键，再结合 MotionID，不能只按 Bank ID 猜路径。
3. **片段层**：选择标识对应的片段名、帧数、帧率、循环性与可恢复的时长。
4. **事件层**：事件轨的名称、开始/结束帧和值；碰撞、控制、声音和 VFX 分别记录，不把“事件出现”直接写成“玩法状态已经改变”。

以下两条边必须与上述四层分开验收：

- `Command/Skill/ActionInterface → 具体动画状态` 的调度或适配边；状态存在不代表已经知道运行时为何选中它。
- `动画事件 → 游戏逻辑副作用` 的处理器边；事件名或参数不能替代真正修改生命、控制权或命中状态的方法。

通用闭合链是 `状态/动作节点 → 引擎实际使用的选择键或资源引用 → Clip/动画容器 → 事件轨`。没有恢复状态间 transition 与条件时，不得把相邻编号、同名前后缀或同一容器中的多个状态串成确定播放顺序；它们应呈现为候选分支或独立状态。

## 输出结构

1. 动画功能目录与变体矩阵。
2. 参数、状态、层和资产关系图。
3. 关键动作时间轴及事件表。
4. Root Motion、IK、Warping 和物理层的职责模型。
5. 动画与技能、AI、音效、VFX 的接口。
6. 性能策略、未知项和验证实验。
