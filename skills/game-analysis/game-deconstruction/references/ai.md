# AI 拆解维度

## 分析目标

从真实 AI 资产、类型字段和资源引用建立“感知配置 → 世界状态 → 决策图/包 → 动作接口 → 导航/技能/动画”的白盒模型。

## 检查清单

### 感知与信息

- 定位视觉、听觉、伤害、事件、阵营过滤和队友共享对应的资产类型与组件引用。
- 导出距离、视角、遮挡、延迟、遗忘时间、形状、碰撞过滤和警觉阶段字段。
- 追踪感知配置到角色模板、控制器、世界状态键和目标数据的引用。
- 查找更新间隔、LOD、预算或难度覆盖字段；没有字段证据时保持未知。

### 世界表示

- 解析黑板/schema、标签、目标列表、威胁、占位点和环境查询的键名、类型、默认值与资源路径。
- 通过对象归属和引用判断状态属于个体、小队、阵营还是全局。
- 记录更新、失效、广播和持久化相关字段或处理节点。

### 决策结构

- 根据资产类型、节点拓扑和类名区分状态机、行为树、Utility、GOAP、规划器、规则系统和脚本序列。
- 导出 task/service/decorator/transition、条件、评分、优先级、打断、冷却、随机权重和失败分支。
- 不用单一类型名断言完整框架；以父子节点、字段和跨资产引用闭合验证。

#### 评分闭合的五层门槛

“找到权重字段”不等于“还原评分公式”。涉及 Utility、候选选择或目标排序时，必须依次闭合：

1. **单项输出**：每个 evaluator/consideration 的输入、真假值或曲线输出、取值范围和失败默认值。
2. **聚合**：各项怎样归一化、加权、相加/相乘，以及总权重为零时怎样处理。
3. **附加分**：人格、策略、连续性、当前行为惯性、随机项等在何处加分或扣分。
4. **优先级**：Layer、Rank、GoalPriority 等究竟是先过滤候选，还是进入分数公式；没有调用证据不得混写。
5. **排序与平局**：比较键、升降序、相等返回值、排序稳定性和最终 tie-breaker。

报告必须用一份真实资产代入公式，至少算出两个可复核样例。还要确认评分发生在单个 AI、小队共享上下文、导演系统还是中央仲裁器中；不得无证据把一种上下文写成另一种。

### 行为与移动

- 建立行为清单：巡逻、调查、搜索、占位、追击、撤退、掩体、攻击、支援、脚本行为。
- 分析导航、局部避障、队形、跳跃/攀爬、智能对象和卡住恢复。
- 记录移动速度、转向、停止距离和动画约束如何影响路径执行。

### 战术与群体

- 目标选择、威胁计算、攻击令牌、空间槽位、角色分工和队友协同。
- 数量变化是否改变进攻频率、包抄、轮换或等待行为。
- 小队信息共享与个体感知如何发生冲突。

### 难度与可读性

- 区分数值增强、信息优势、反应时间、决策质量、行为解锁和导演系统。
- 检查预警、让步、射偏、排队和镜头外规则是否服务玩家体验。
- 识别看似“聪明”但实际由关卡脚本或作弊信息产生的行为。

### 配置与调试

- 建立已提取字段字典：阈值、曲线、权重、冷却、标签、行为集合、角色模板和难度覆盖。
- 记录原型、继承、组合、表格、图和脚本参数的实际引用关系。
- 保留未解析类型、字段、GUID/ObjectID 和路径，禁止以常见引擎惯例补全。

## 白盒提取与验证

- 从角色/遭遇模板追踪到 Controller、决策资产、schema/黑板、感知、导航、技能和动画。
- 对 Decision/Goal/Behavior/FSM 资源导出节点拓扑、条件、评分、过程和引用目标。
- 对评分代码同时追踪单项输出、聚合、附加分、优先级门、排序比较器和平局行为；任一层未闭合时，只声明已恢复的局部公式。
- 对基础包与补丁层做字段级差异，确认同路径 AI 配置的覆盖变化。
- 重复提取并比较文件哈希；用第二解析器或类型注册表复验关键字段。
- 运行时实验仅用于确认已提取阈值或字段语义，不得生成缺失配置。

## 输出结构

1. AI 角色与行为目录。
2. 感知—决策—执行数据流。
3. 个体状态图与小队协作模型。
4. 已提取配置字段字典、原始路径、对象 ID 与引用边。
5. 难度和玩家可读性策略。
6. 已解析的性能/更新预算字段与未知项。
7. 未解析类型、断裂引用和下一解析路线。
