# 呆猫知识漫画质量清单

## A. 知识正确性（任一失败即阻塞）

- [ ] 核心结论能由引用来源支持。
- [ ] 事实、推断、类比和笑点彼此分开。
- [ ] 数字、单位、时间、版本、条件均正确。
- [ ] 医疗/法律/金融/安全内容有权威来源与必要警示。
- [ ] 视觉隐喻没有把相关性画成因果、把比例画成绝对数量或把例子画成普遍规律。
- [ ] 末格口诀没有遗漏决定性的例外条件。

## B. 教学叙事

- [ ] 第一格提出明确问题，而不是只报标题。
- [ ] 每格只承担一个新信息动作。
- [ ] 至少有一个机制图示，而非全靠对白。
- [ ] 至少处理一个常见误区、反例或边界。
- [ ] 最后一格给出能独立复述的一句话结论。
- [ ] 删除任何不影响理解的重复对白。

## C. 角色一致性

逐格对照五图参考与 Character Lock：

- [ ] 两只高尖三角耳及蓝紫头套轮廓稳定。
- [ ] 奶油色圆脸盘大小与位置稳定。
- [ ] 蓝紫/靛蓝猫耳头套与正面躯干连成一体，没有黄色身体、黄色四肢或独立衣摆。
- [ ] 暖米白椭圆脸盘、球形圆手和短圆脚稳定，没有发明浅色肚皮。
- [ ] 两只圆手保持球形/短椭球形并贴近蓝色躯干，连接极短或隐藏；没有长前臂、肘部、手腕、手掌、手指或人类关节。
- [ ] 巨大黑色圆眼图形、粗环与白色弧形高光稳定，没有玻璃珠眼、彩色虹膜、睫毛或眉毛。
- [ ] 连续粗黑卷曲猫嘴稳定，没有独立鼻子、Y 形嘴或写实口鼻。
- [ ] 所有画格的眼睛开合、视线、白弧位置与卷曲猫嘴完全固定，没有眉毛、怒眼、闭眼笑、张嘴或嘴角变化。
- [ ] 没有蓝色领巾、围巾、后结或飘带；背后结构没有被误画成围巾结。
- [ ] 湿润、逆光或动作状态只改变光泽/明暗，不改变官方色块与脸谱结构。
- [ ] 没有多肢、错尾、写实长毛、人手或身份漂移。
- [ ] 每格默认只有一只呆猫。

## D. 口癖与人物感

- [ ] 首格或前两格自然出现“老大”。
- [ ] “喵”有节制，不是每句机械追加。
- [ ] 呆萌来自认真动作和情境反差，不来自讲错知识。
- [ ] 未把原创句子标成官方原台词。
- [ ] 没有与呆猫无关的网络猫梗混入角色设定。

## E. 神韵与渲染

- [ ] 先用一句话写清角色当前认真想完成的行动，眼神、头部和道具共同指向该目标。
- [ ] 神韵能读成“清澈、认真、可靠、略笨拙”，而不是无意图的空脸或泛化 kawaii 表情。
- [ ] 脸谱不承担情绪；没有大笑、张嘴、舌头、牙齿、夸张哭脸、人类眉毛或眼睛开合变化。
- [ ] 至少一个身体动作承担情绪：头部整体朝向、肩膀收紧、手脚内扣/张开、重心偏移、抬脚或道具关系。
- [ ] 动漫特效只位于脸盘外、头套外或角色周围，每格最多一种主特效，不覆盖或牵引五官。
- [ ] 遮住脸部后仍能从肢体、道具与特效读出动作意图；遮住身体后各格脸谱近似同一张固定贴图。
- [ ] 远距离触达通过身体前倾、侧移、踮脚或道具靠近实现，没有通过伸长圆手/前肢实现。
- [ ] 头身比例短而紧凑，不像高个毛绒玩具，也不采用流畅英雄姿势。
- [ ] 材质为克制的游戏资产感：哑光块面、少量大褶皱、轻微关节压缩和柔和环境遮蔽。
- [ ] 没有均匀细密织纹、长绒、黏土、亮面塑料、商品摄影精修或 Pixar/Disney 式通用 3D 萌物漂移。
- [ ] 若没有用户提供或授权的原始参考图，已把“内部一致性通过”和“原图相似度未核验”分开报告。
- [ ] 迭代每轮只修改一个变量；默认不超过 4 轮，同一维度连续两轮无改善时提前停止。

## F. 字体与版式

- [ ] 图片层无乱码、伪汉字、水印和多余 Logo。
- [ ] 所有中文使用后期文字层排版。
- [ ] 气泡尾指向正确说话者，不遮挡脸和关键图示。
- [ ] 手机宽度预览时最小正文仍清晰可读。
- [ ] 格间距、阅读方向和编号明确。
- [ ] 标题、正文、图注、来源有清晰层级。
- [ ] 页脚包含来源短链/名称和同人声明。

## G. 交付完整性

- [ ] 保存知识卡、脚本、分镜与最终文字清单。
- [ ] 保存全局提示词、逐格提示词、负面提示词。
- [ ] 记录图像模型、模型版本（若可得）、比例及关键参数。
- [ ] 记录知识核实日期。
- [ ] 若缺少 Gemini 视觉核验或成图工具，已明确声明而非静默替代。
- [ ] 保存神韵校准稿、逐轮单变量修改记录与最终采用的提示词。

## 重做优先级

1. 错误知识或误导图示。
2. 角色身份漂移。
3. 错字、乱码、气泡错误。
4. 阅读顺序与信息过载。
5. 表情、背景与装饰美化。

只重做失败画格；除非知识结构本身错误，否则不要整页重新随机生成。
