# 呆猫知识漫画质量清单

## A. 知识正确性（任一失败即阻塞）

- [ ] 核心结论能由引用来源支持。
- [ ] 事实、推断、类比和笑点彼此分开。
- [ ] 数字、单位、时间、版本、条件均正确。
- [ ] 医疗/法律/金融/安全内容有权威来源与必要警示。
- [ ] 视觉隐喻没有把相关性画成因果、把比例画成绝对数量或把例子画成普遍规律。
- [ ] 末格口诀没有遗漏决定性的例外条件。

## B. 教学叙事

- [ ] 第一格提出明确问题，而不是只报标题。
- [ ] 每格只承担一个新信息动作。
- [ ] 至少有一个机制图示，而非全靠对白。
- [ ] 至少处理一个常见误区、反例或边界。
- [ ] 最后一格给出能独立复述的一句话结论。
- [ ] 删除任何不影响理解的重复对白。

## C. 角色一致性

逐格对照五图参考与 Character Lock：

- [ ] 两只高尖三角耳及蓝紫头套轮廓稳定。
- [ ] 奶油色圆脸盘大小与位置稳定。
- [ ] 巨大圆黑眼、微小高光、简化口鼻稳定。
- [ ] 芥末黄色圆身体、短四肢稳定。
- [ ] 蓝色领巾存在，背面场景可见系结。
- [ ] 没有多肢、错尾、写实长毛、人手或身份漂移。
- [ ] 每格默认只有一只呆猫。

## D. 口癖与人物感

- [ ] 首格或前两格自然出现“老大”。
- [ ] “喵”有节制，不是每句机械追加。
- [ ] 呆萌来自认真动作和情境反差，不来自讲错知识。
- [ ] 未把原创句子标成官方原台词。
- [ ] 没有与呆猫无关的网络猫梗混入角色设定。

## E. 字体与版式

- [ ] 图片层无乱码、伪汉字、水印和多余 Logo。
- [ ] 所有中文使用后期文字层排版。
- [ ] 气泡尾指向正确说话者，不遮挡脸和关键图示。
- [ ] 手机宽度预览时最小正文仍清晰可读。
- [ ] 格间距、阅读方向和编号明确。
- [ ] 标题、正文、图注、来源有清晰层级。
- [ ] 页脚包含来源短链/名称和同人声明。

## F. 交付完整性

- [ ] 保存知识卡、脚本、分镜与最终文字清单。
- [ ] 保存全局提示词、逐格提示词、负面提示词。
- [ ] 记录图像模型、模型版本（若可得）、比例及关键参数。
- [ ] 记录知识核实日期。
- [ ] 若缺少 Gemini 视觉核验或成图工具，已明确声明而非静默替代。

## 重做优先级

1. 错误知识或误导图示。
2. 角色身份漂移。
3. 错字、乱码、气泡错误。
4. 阅读顺序与信息过载。
5. 表情、背景与装饰美化。

只重做失败画格；除非知识结构本身错误，否则不要整页重新随机生成。
