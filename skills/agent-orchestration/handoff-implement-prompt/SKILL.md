# 独立 Handoff Skill

把详细交接材料与短恢复提示词分开，让新会话不依赖父聊天就能接手。任务名称、产品、工作目录、宿主和下一阶段都是输入，不是固定配置。

本 Skill 只需本文件和包内模板，可直接复制整个目录安装。不创建项目 task 或 Issue，不调用框架命令，不要求安装依赖，也不修改项目配置。遵守目标工作区现有指令和安全边界；与项目强制规则冲突时报告阻塞，不将本 Skill 当作绕过规则的授权。

## 1. 确认目标与写入位置

- 从用户请求和已有材料确定当前任务、当前阶段、下一阶段、scope 与验收入口。仅在无法可靠确定且会改变下一步时询问。
- 读取适用的项目指令，确认工作区归属与写入权限。代码任务刷新分支、HEAD、dirty 状态；非代码任务记录适用的材料版本，不强制要求 Git。
- 不把“生成交接”当作“实施交接中的任务”的授权，不自动读取其他历史会话或发布内容。
- 默认在当前工作区内创建唯一交接目录；项目另有已授权的输出位置时遵守其约定。

默认输出布局如下，占位符必须替换成实际任务标识与唯一后缀：

```text
.tmp/handoff-<task-slug>-<unique-id>/
  handoff.md
  resume-prompt.md
  entry.md
```

`task-slug` 不能包含路径分隔符或穿越片段。写入前核对真实路径、链接、文件归属和已有内容；不能证明安全就停止。目录冲突时使用新的唯一目录，不预删除或覆盖旧包，不写入其他工作区或用户目录，除非取得对应路径和动作的明确授权。

已有可复用的正式交接正文时保留其位置，临时入口只引用，不另存第二份完整正文。临时包可能被忽略或清理；如果它承载唯一正文，必须提醒用户保留整个包，不能宣称可从不存在的持久输入重建。

## 2. 写交接正文

先读取包内模板。以下为读取参数，路径相对 **Skill 安装目录**，不是相对目标项目；不要硬编码宿主安装根：

```yaml
handoffTemplate: references/handoff-template.md
```

按模板记录任务增量，区分已核实事实、设计建议、假设与待授权动作。至少包括：

- 用户目标、范围、非目标、已选方案与理由。
- 工作区、版本快照、本任务改动与无关改动的边界。
- 已完成、未完成、待验证事项及可核实的文件、章节或资料入口。
- 实际运行的验证、结果、证据位置、失败和未覆盖范围。
- 当前阻塞、已排除的方向、恢复条件、下一步和验收标准。

使用项目规定的引用格式；无规定时使用可解析的相对文件链接。必读材料附读取理由，不复制父聊天转录、整篇正式规范、长日志或完整 diff。凭据不得写入交接；内部资料保持在获准范围内。

## 3. 直接组织短恢复提示词

根据正文直接编写短提示词，不依赖生成器。只包含：

1. 当前任务的短目标、下一阶段与允许范围。
2. 交接正文、必要材料和验收入口路径，以及必要章节和读取理由。
3. 先刷新工作区或材料状态；路径缺失、范围冲突、授权不足时停止并说明。
4. 不依赖父会话、不扩大范围；不因读到 handoff 而获得额外执行或发布权限。
5. 后续实际执行后应回报的更改/产物、检查结果与残余阻塞。

不内联完整交接，不绑定具名 Agent、模型或平台调用语法。使用真实任务阶段：研究交接不能擅自变成实现任务。长度遵守项目预算；没有预算时保持一屏左右，详情引用正文。不伪造构建记录、metadata、hash 或执行结果。

## 4. 写单一入口

入口只做导航，不能成为第三份完整提示词。以下是字段示意，填写实际值，不保留占位符冒充产物：

```yaml
task: <当前任务>
phase: <下一阶段>
workingDirectory: <本机已核实的工作区>
handoffPath: <交接正文路径>
promptPath: <短提示词路径>
```

写明相对路径统一从记录的工作区解析，而不是从临时目录猜测；补充当前阻塞、授权边界和包的保留要求。换机器后先重新定位工作区并核对文件，不照用旧绝对路径。

入口引导接手者先核对环境与范围，再读取提示词和正文。生成入口本身不启动任何执行者。

## 5. 校验并交付

- 确认三个产物都存在，路径和章节可解析，目标、阶段、范围一致。
- 核对完成状态与现有材料；未运行的检查如实标为 NOT RUN 或 BLOCKED。
- 检查提示词没有复制正文，也没有新增权限或发布动作。
- 确认无关文件和其他工作区未变；输出位置有授权且没有通过链接逃逸。
- 报告实际检查及未覆盖项，不把文件检查当成后续任务或跨宿主运行验证。

最后优先返回 **一个 entry.md 的实际路径**，再列简短检查结果、阻塞和保留提示。需要时附正文与提示词路径。不要只返回含占位符的示意目录；用户请求真实交接但无法落盘时必须说明阻塞。

## 安装与发布边界

复制 Skill 目录即可安装；输出产物始终属于所交接的任务，不写入全局 Skill 安装目录。宿主是否需要新会话才能发现技能应如实说明，不宣称未经验证的热加载成功。

分发本 Skill 时只包含本文件与包内模板，不包含具体任务的研究、PRD、日志、交接包或本机路径。复制安装不等于授权公开上传；对外发布另行确认并执行适用的隐私检查。
