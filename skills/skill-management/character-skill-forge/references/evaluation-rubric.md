# 角色 Skill 视觉与工程验收

## 评分方式

每项 `0=失败，1=勉强，2=通过`。身份、表情策略和肢体拓扑任一为 0，立即阻塞后续整页生成。

| 维度 | 2 分标准 |
|---|---|
| 证据诚实度 | 观察、官方、推断、创作默认和未知项清楚分层 |
| 身份锚点 | 剪影、主色块、标志部件和比例在测试图中稳定 |
| 表情策略 | fixed/bounded/expressive 选择有证据，五官变化不越界 |
| 肢体拓扑 | 附肢数量、关节、手足类型和触达机制不随动作漂移 |
| 渲染锁 | 媒介、材质、纹理尺度和光照保持角色原有表现逻辑 |
| 动作神韵 | 不看文字也能读懂行动意图，且未牺牲身份结构 |
| 内容能力 | 知识正确、教学节奏清楚、文字与画面分层 |
| 可复现性 | 另一个 Agent 只读目标 Skill 即可执行并知道何时停止 |

通过门槛：总分至少 `14/16`，且身份锚点、表情策略、肢体拓扑均为 2。只有一张参考图时，“未出现视角相似度”不计入通过结论，必须继续列为未知。

## 三层视觉审查

### A. 锚点图

逐项回答：

- 与原始参考并排时，第一眼的剪影和最大色块是否一致？
- 面部结构属于正确的表达模式吗？
- 手足和关节是否被生成模型擅自人形化？
- 材质是否滑向通用毛绒、黏土、亮塑料、通用动漫或其他错误媒介？
- 图中动作是否服务于一个清楚的行动意图？

任一身份阻塞项失败，不进入九宫格。

### B. 九宫格

把九格同时查看，做两次遮挡测试：

1. 遮住脸：是否仍能从身体、道具和构图读出动作，并保持同一角色？
2. 遮住身体：脸部是否遵守 fixed/bounded/expressive 策略，而不是九种随机表情？

再检查：

- 托举、推拉、奔跑时附肢拓扑是否变化。
- 强情绪是否增加了未经允许的眉、牙、舌、手指或关节。
- 环境和光照变化是否改坏主色块和材质。
- 是否出现多肢、错尾、重复角色、伪文字、水印或错误标志。

### C. 真实试例

在四格知识漫画里检查：

- 同一 Character Lock 是否逐格重复，而不是只在全局写一次。
- 角色表演是否帮助理解因果，而不是制造错误知识。
- 中文是否由后期文字层完成。
- 失败画格是否能单独重做，避免整页随机化。

## 单变量诊断

一次只选择一个主因：

- `identity`：剪影、色块、标志部件。
- `expression`：眼眉嘴和外围特效边界。
- `anatomy`：附肢、关节、抓握和触达。
- `proportions`：头身比、长度和体块。
- `render`：媒介、材质、纹理和光照。
- `action_spirit`：重心、节奏、道具和角色意图。

如果问题同时跨多个维度，先修身份，再修表情/肢体，然后修渲染和神韵。不要通过改背景掩盖角色错误。

## 停止规则

满足任一条件就停止自动迭代：

- 已达到预算上限，默认 4 轮。
- 同一维度连续两轮分数未提高。
- 缺少决定性参考视角，继续生成只会扩大推断。
- 图像工具不支持可靠参考图输入或无法比较结果。
- 修订需要改变用户未授权的发布、下载或模型使用范围。

停止不是失败掩盖。报告当前最好版本、通过项、剩余偏差、缺失证据以及下一步需要什么。
